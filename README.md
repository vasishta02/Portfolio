# Vasishta Chandala — Portfolio

Personal portfolio covering data science, applied AI, machine learning, and data engineering.

## Publish with GitHub Pages

In repository **Settings → Pages**, select **Deploy from a branch**, then **main** and **/(root)**, and save.

Expected site address after Pages is enabled: https://vasishta02.github.io/Portfolio/

## Files

- `index.html` — portfolio content
- `style.css` — responsive layout and styles
- `app.js` — project filters and case studies
- `.nojekyll` — serves these static files without Jekyll processing

Edit these files and commit to `main` to update the published site.
